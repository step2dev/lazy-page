# Contributing

Thank you for considering contributing to Lazy Page.

## Pull Requests

- Keep changes focused and backwards-compatible where possible.
- Add or update tests for behavior changes.
- Run `composer test`, `composer analyse`, and `composer format` before submitting.
- Keep public APIs documented in the README when relevant.

## Issues

Please include clear reproduction steps, expected behavior, actual behavior, Laravel version, and PHP version when reporting a bug.
